# 💰 ExpenseTracker Pro

A professional personal expense tracking application that helps you manage your finances with ease. Built with vanilla JavaScript, HTML, and CSS - no frameworks required!

## ✨ Features

- **Quick Expense Entry** - Add expenses with amount, category, date, and notes
- **Auto Date Detection** - Automatically sets today's date for quick entry
- **Custom Categories** - Create your own categories with custom colors
- **Time-based Filtering** - View expenses by month, quarter, year, or all time
- **Search & Filter** - Find expenses by keyword or category
- **Professional Excel Export** - Download detailed reports with multiple sheets
- **Local Storage** - All data stays in your browser, no server required
- **Responsive Design** - Works perfectly on desktop and mobile
- **Summary Statistics** - See totals for today, this month, last month, and this year
